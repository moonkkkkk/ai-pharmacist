# 用户旅程地图

## 主旅程：王建国（自理型老人）的慢病用药全链路

### 旅程总览

```
医院开药 → 取药回家 → 整理药盒 → 每日服药 → 漏服/异常 → 复诊
  │           │           │           │           │          │
  ▼           ▼           ▼           ▼           ▼          ▼
 阶段1      阶段2       阶段3       阶段4       阶段5      阶段6
 多院开药   药盒到家    药品上架    日复一日    意外时刻    三个月后
```

---

## 阶段 1：多院开药——混乱的起点

**时间**：每 1-3 个月发生一次

| 维度 | 详情 |
|---|---|
| 用户行为 | 去三甲医院心内科开降压药 → 去内分泌科开降糖药 → 顺便在药店买阿司匹林和钙片 |
| 触点 | 医院 HIS 系统、纸质处方、医保卡、药店小票 |
| 情绪 | 😟 困惑——"三个地方的药，到底能不能一起吃？" |
| 痛点 | 不同科室/HIS 之间信息不互通，没有一个地方能看到全部用药清单 |
| 机会 | AI 药师首次录入时可做一次「全量用药建档」 |

**AI 介入点**：❌ 暂不介入（MVP 手动录入，V2 拍照识别）

**情绪值**：😐 3/5（习惯了，但每次都不踏实）

---

## 阶段 2：药盒到家——物理世界的碎片

**时间**：开药当天

| 维度 | 详情 |
|---|---|
| 用户行为 | 拎着一袋药回家，药盒有大有小，说明书字比蚂蚁还小 |
| 触点 | 药盒包装、药品说明书 |
| 情绪 | 😣 烦躁——"这盒白的、这盒黄的，哪个是早上吃的来着？" |
| 痛点 | 药品说明书字太小完全看不清，药盒长得像容易搞混 |
| 机会 | ⭐ 首次录入时子女帮老人设置，一次设置长期复用 |

**AI 介入点**：❌ 不介入（录入由子女帮老人完成，走结构化表单）

**情绪值**：😣 2/5

---

## 阶段 3：整理药盒——每天的仪式，也是隐患

**时间**：每天早上

| 维度 | 详情 |
|---|---|
| 用户行为 | 把一天三顿的药从不同药盒里拿出来，放到小药盒的三个格子里 |
| 触点 | 分格药盒（儿子给买的，用了两周就懒得用了）、餐桌 |
| 情绪 | 😩 疲惫——"每天都要分，太麻烦了，今天直接吃吧" |
| 痛点 | 分药耗时 3-5 分钟，手抖容易掉药片，分完经常忘了是不是分对了 |
| 机会 | ⭐ 用药时间表自动生成后，老人只需"按格子吃"，不需要分 |

**AI 介入点**：❌ 不介入，规则引擎生成时间表

**情绪值**：😩 2/5（从认真分药 → 逐渐懈怠）

---

## 阶段 4：日复一日——最核心的用药场景（每日 3 次）

这是产品最核心的战场，展开为 4 个子场景：

### 4A. 早晨服药（依从率较高）

| 维度 | 详情 |
|---|---|
| 场景 | 07:00 起床 → 07:30 吃早饭 → 07:50 吃降压药+阿司匹林 |
| 依从率 | 较高，因为早上清醒 + 多年习惯 |
| 痛点 | 早饭吃了西柚/喝豆浆，不确定是否能和药一起吃 |
| 机会 | ⭐ 提醒文案中附带食物禁忌提示 |

**AI 介入点**：✅ **核心 AI 场景**
- 🤖 LLM 生成生活化提醒文案（"王叔叔早上好，降压药和阿司匹林该吃了。早饭可别碰西柚哦"）
- 🔊 TTS 转语音播报

**期望情绪**：😊 4/5——温暖但不打扰

### 4B. 午间服药（最高漏服风险）

| 维度 | 详情 |
|---|---|
| 场景 | 11:30 午饭 → 12:00 午睡前吃二甲双胍+阿卡波糖 |
| 依从率 | 最低——午餐时间不固定，午睡一醒就忘了 |
| 痛点 | 这顿药最容易漏，没人提醒根本想不起来 |
| 机会 | ⭐⭐⭐ 午间提醒是产品的最高价值场景 |

**AI 介入点**：✅ **产品价值最高的 AI 场景**
- 🤖 LLM 根据天气、时间生成差异化提醒（"午睡醒了？降糖药随餐吃刚刚好"）
- 🔊 TTS 语音播报
- 📱 如果 10 分钟内未确认，推送二次提醒

**期望情绪**：😌 4/5——"幸好有小云提醒"

### 4C. 晚间服药（第二漏服高峰）

| 维度 | 详情 |
|---|---|
| 场景 | 17:30 晚饭 → 18:00 吃降压药（缬沙坦） |
| 依从率 | 中等，看电视入迷了可能忘 |
| 痛点 | 晚饭时间不固定，偶尔和老朋友出去喝酒就忘吃药 |

**AI 介入点**：✅ **AI 场景**
- 🤖 晚间提醒文案（"今天降温了，吃完药早点休息"）
- 🔊 TTS

**期望情绪**：😊 4/5

### 4D. 每周特殊药（最易混淆）

| 维度 | 详情 |
|---|---|
| 场景 | 每周一早上吃阿仑膦酸钠（骨质疏松，一周一次） |
| 依从率 | 很低——经常搞混"这周吃没吃？" |
| 痛点 | 不是每天吃，更容易忘。吃错了（吃两次）又担心副作用 |

**AI 介入点**：✅ **AI 场景**
- 🤖 特殊提醒文案（标注"一周一次"）
- 📊 子女端通知"本周特殊药已服用"

**期望情绪**：😌 4/5

---

## 阶段 5：意外时刻——漏服、错服、异常

**时间**：随机发生（月均 3-5 次）

| 子场景 | 现状 | AI 产品介入方案 |
|---|---|---|
| 5A. 漏服发现 | 老人不记得吃了没，索性不吃了 | 到点未确认 → 10分钟后二次提醒 → 30分钟后通知子女 |
| 5B. 疑似重复服用 | 老人忘记吃过，又吃了一次 | 查看用药记录时间戳 ← 确认已服用则提示"您10分钟前已经吃过啦" |
| 5C. 身体不适 | 头晕/恶心，不确定是不是药的副作用 | 出现不适 → 提醒"如有不适请先停药并联系医生"（不走AI判断） |
| 5D. 子女远程获知 | 子女打电话来问，老人说"吃了吃了" | 子女端查看每日用药打卡状态（绿色=已服，黄色=延迟，红色=未服） |

**AI 介入点**：
- ✅ 漏服二次提醒（规则引擎 + LLM 温柔催促）
- ✅ 子女端推送（"您父亲的午间药尚未确认，是否需要电话提醒？"）
- ⚠️ 注意：出现不适不交给 AI 判断，只做预设安全兜底

**情绪值**：
- 老人：😰 2/5（漏服→焦虑→"反正也忘了，不吃了"）
- 子女：😨 1/5（获知漏服时最焦虑）

---

## 阶段 6：三个月后——复诊

**时间**：每 3 个月一次

| 维度 | 详情 |
|---|---|
| 用户行为 | 去医院复诊，医生问"这三个月药吃得怎么样？有什么不舒服？" |
| 现状 | 老人凭记忆回答，说不清楚，"还行吧，有时候忘" |
| 痛点 | 医生无法获取真实用药数据，无法判断药效不佳是因为"药不对"还是"没按时吃" |
| 机会 | ⭐ 生成三个月用药报告，老人或子女可以出示给医生 |

**AI 介入点**：✅ **V2 AI 场景**
- 📊 用药报告自动汇总（总服药次数、漏服次数、漏服分布、平均确认时间）
- 📄 生成一份 PDF "用药小结"（子女可转发给医生）

**情绪值**：😐 3/5——现状已经习惯了"说不清"，但有报告会更好

## 情绪曲线总览

```
情绪值
  5 │                    ●━━━●     早晨/晚间服药（有AI提醒后）
    │                   ╱       ╲
  4 │              ●───╱         ╲
    │             ╱                ╲
  3 │  ●────●───╱                  ╲───●───●     复诊
    │ ╱                                ╲
  2 │╱        ●                         ╲───●     漏服时刻
    │      整理药盒
  1 │
    └─────────────────────────────────────────────
     阶段1    阶段2    阶段3    阶段4      阶段5    阶段6
     多院开药  取药回家  整理药盒  每日服药   意外时刻  三个月后
```

**核心发现**：
- 情绪最低点在**阶段 5（漏服时刻）**——这也是产品的核心价值点
- **阶段 4 每日服药**是产品发挥最大作用的舞台——把日常从 2 分提到 4 分
- 阶段 1-2 不需要 AI 介入，但产品体验的起点（录入）必须极简
