# 用户画像

## 画像总览

三张画像分别对应自理型老人、半依赖型老人、远程子女。其中子女是付费决策者，老人是终端使用者。

| 画像 | 年龄段 | 角色 | 核心诉求 | 付费意愿 |
|---|------|------|----------|---------|
| 王建国 | 65-75 | 自理型老人 | 需要提醒但不要被管 | 低（子女付） |
| 李秀兰 | 75+ | 半依赖型老人 | 语音呼入，零操作 | 无（子女付） |
| 陈明 | 35-45 | 远程子女 | 获知父母用药状态 | 高（决策者+付费者） |

---

## 画像一：王建国——自理型老人（P0 主用户）

### 基本信息

| 维度 | 详情 |
|---|---|
| 姓名 | 王建国 |
| 年龄 | 68 岁 |
| 居住地 | 杭州拱墅区 |
| 居住状态 | 和老伴同住，儿子在上海工作 |
| 退休前职业 | 国营工厂车间主任 |
| 月退休金 | 5200 元 |
| 学历 | 初中 |

### 健康状况

| 维度 | 详情 |
|---|---|
| 慢病 | 高血压（15年）+ 2型糖尿病（5年） |
| 日均服药 | 5 种：硝苯地平、缬沙坦、二甲双胍、阿卡波糖、阿司匹林 |
| 服药频次 | 早 3 种、午 1 种、晚 1 种 |
| 近一年漏服经历 | 每月漏服 3-5 次，主要是午间那顿 |
| 近一年错服经历 | 有 2 次重复吃了早上的药 |

### 数字化能力

| 维度 | 详情 |
|---|---|
| 智能手机 | 红米 Note，儿子买的，用了 3 年 |
| 常用 App | 微信（每天刷）、抖音（晚上看）、今日头条 |
| 微信能力 | 会发语音、会看公众号、会点小程序、不会打字 |
| 对 AI 的态度 | "就是那个能聊天的机器人是吧？"——听说过但没用过 |
| 手机字体 | 调到了最大号 |

### 典型一天

```
06:30  起床，量血压（老伴帮忙记在本子上）
07:00  吃早饭，饭后吃降压药+阿司匹林（3种）
08:00  去公园遛弯，和老伙计下棋
11:30  午饭，饭后吃二甲双胍+阿卡波糖——这顿最容易忘
12:30  午睡
14:00  看今日头条，转发养生文章到家族群
17:30  晚饭，饭后吃缬沙坦
19:00  刷抖音，看抗日剧
21:30  睡觉
```

### 核心痛点

1. **午间那顿药经常忘**：午睡醒来迷迷糊糊，没人提醒就想不起来
2. **分不清药能不能一起吃**：医生只说"饭后吃"，但三种早上的药能一起吃吗？不确定
3. **不想让儿子觉得自己"不行了"**：儿子每次打电话都问"药吃了吗"，他觉得烦但也知道是关心
4. **西柚到底能不能吃**：朋友圈有人说降压药不能吃西柚，但说不清为什么

### 对 AI 产品的期望

- "提醒我可以，但别像闹钟一样吓人"
- "字要大，别让我找半天"
- "不要搞得我儿子天天盯着我吃没吃药"
- "能告诉我什么不能吃就行"

### 情绪触发点

- 😤 反感：被监控感、"老年人专用"的可怜语气
- 😊 好感：被尊重、语气像老朋友、关心他的生活而不只是"吃药"

## 画像二：李秀兰——半依赖型老人（P1 用户）

### 基本信息

| 维度 | 详情 |
|---|---|
| 姓名 | 李秀兰 |
| 年龄 | 78 岁 |
| 居住地 | 南京江宁区，和女儿同小区不同楼 |
| 居住状态 | 独居，女儿一家住在隔壁楼 |
| 退休前职业 | 小学语文教师 |
| 月退休金 | 6800 元 |
| 学历 | 中专 |

### 健康状况

| 维度 | 详情 |
|---|---|
| 慢病 | 高血压（20年）+ 冠心病（8年）+ 骨质疏松 |
| 日均服药 | 7 种（含阿仑膦酸钠，每周一次） |
| 服药频次 | 早 3 / 午 1 / 晚 2 / 每周一早 1 |
| 听力 | 右耳轻度下降，正常音量可交流 |
| 视力 | 老花眼，看小字需要放大镜 |
| 行动能力 | 能自己走路买菜，但上下楼梯吃力 |

### 数字化能力

| 维度 | 详情 |
|---|---|
| 智能手机 | 女儿给买的华为，主要用来接电话和看微信 |
| 常用 App | 微信（只看消息不主动发）、电话 |
| 微信能力 | 会接语音电话、会播放语音消息、不会发消息 |
| 打字能力 | 完全不会 |
| 手机操作意愿 | 极低——"字太小了，点了半天不知道点到哪里去了" |

### 典型一天

```
05:30  自然醒，听收音机（江苏新闻广播）
07:00  女儿送早饭过来，盯着她把早上的药吃了
08:30  下楼在小区花园坐坐，和老邻居聊天
10:30  回家准备午饭（自己简单做点）
11:30  午饭，午饭后的药经常忘——女儿不在这顿
12:30  午睡（睡得久，经常睡到 15:00）
15:30  女儿过来看一眼，或者打座机确认她没事
17:00  晚饭，女儿送饭过来，吃完盯着吃药
19:00  看央视新闻联播，看天气预报
20:30  睡觉
```

### 核心痛点

1. **午间无人盯防**：女儿早晚都来，但中午那顿药没人看，经常就忘了
2. **药太多分不清**：7 种药，有的早上吃有的晚上吃，阿仑膦酸钠一周一次老是搞混
3. **不会用智能手机**：女儿给她装过用药提醒 App，她不会操作，放弃了
4. **摔过一次**：去年因为漏吃降压药血压高了头晕摔了一跤，女儿后怕了很久

### 对 AI 产品的期望

- "能动嘴就不要让我动手"
- "声音要大，语速要慢"
- "我不会按那些按钮，你直接跟我说就行"

### 情绪触发点

- 😤 反感：让她操作手机屏幕、让她做选择题
- 😊 好感：主动说话（语音呼入）、像广播员一样清晰、关心她的安全

## 画像三：陈明——远程子女（P0 付费决策者）

### 基本信息

| 维度 | 详情 |
|---|---|
| 姓名 | 陈明 |
| 年龄 | 38 岁 |
| 居住地 | 上海浦东 |
| 职业 | 互联网公司后端开发 |
| 家庭 | 已婚，孩子 6 岁，父亲王建国在杭州 |
| 年收入 | 家庭年收入 45 万 |
| 回老家频率 | 每月 1 次（高铁 1 小时） |

### 与父母的关系

| 维度 | 详情 |
|---|---|
| 每天通话 | 晚上 8 点左右，打给父亲，问"今天怎么样？药吃了吗？" |
| 最大焦虑 | "他嘴上说吃了，我也不知道是不是真的吃了" |
| 触发事件 | 去年父亲因漏吃降压药导致血压飙升到 180，邻居送医院——陈明是第二天才知道的 |
| 做过什么 | 买过智能药盒（父亲嫌麻烦不用）、设过手机闹钟（父亲说太吵关了） |

### 数字化能力

| 维度 | 详情 |
|---|---|
| 手机 | iPhone 15 Pro |
| 日常工具 | 微信、企业微信、支付宝、美团 |
| 对 AI 态度 | 工作里用 Copilot，对 AI 产品有认知，知道 LLM 能做什么 |
| 付费习惯 | 为父母买过体检套餐、血压计、智能药盒，年均消费 2000-3000 元 |

### 核心痛点

1. **信息不对称**：不知道父母到底吃没吃药，只能靠问，问了也未必是真的
2. **远程无力感**：人在上海，能做的事太少了
3. **怕被嫌烦**：每天问"药吃了吗"自己也觉得啰嗦，但不敢不问
4. **突发恐慌**：最怕接到杭州陌生电话，怕是父亲出事了

### 对 AI 产品的期望

- "我只想知道他今天吃没吃药，别让我每天打电话问"
- "如果漏吃了，第一时间告诉我"
- "不要让我爸觉得我在监视他"
- "每月几十块钱完全能接受，比智能药盒便宜多了"

### 决策逻辑

```
发现父母漏服问题 → 尝试免费方案（电话提醒） → 效果不好 →
购买硬件产品（智能药盒）→ 父母不用，闲置 →
寻找软件方案（App/小程序）→ 关键判断点：
  - 父母会不会用？
  - 我能不能远程知道状态？
  - 价格合理吗？（心理价位 ≤ ¥19.9/月）
```

### 情绪触发点

- 😤 反感：功能复杂不会用、需要父母装 App 注册、漏服了也不通知
- 😊 好感：开箱即用（父母无需操作）、漏服主动通知、价格透明

## 三张画像的关键差异总结

| 维度 | 王建国（自理型） | 李秀兰（半依赖型） | 陈明（子女） |
|------|--------------|------------------|-------------|
| 操作方式 | 小程序点击 | 语音电话呼入 | App/小程序查看 |
| 交互模式 | 主动接收+手动确认 | 被动接收+语音确认 | 查看仪表盘 |
| 核心 AI 能力 | 文案生成 + TTS | TTS 为主 | 数据汇总 |
| 对 AI 的态度 | 好奇但谨慎 | 无感知 | 信任且期待 |
| 拒绝理由 | "太麻烦就不用了" | "不会按不会点" | "父母不用我就不付钱了" |

## 关键洞察（对产品设计的约束）

1. **真正用的人是老人，付费的是子女**——产品必须同时满足双方
2. **老人的操作成本必须趋近于零**——理想状态是：收到消息 → 听 → 按键"1"确认，就完了
3. **子女需要的是"安心感"而非"控制感"**——通知漏服即可，不需要实时监控
4. **语音是第一交互通道**——对自理型老人是增值，对半依赖型老人是必选
