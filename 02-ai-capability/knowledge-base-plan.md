# 知识库构建计划

## MVP 知识库范围

仅覆盖中国慢病老人最常用的 50 种药品。

## 数据源

| 数据源 | 内容 | 获取方式 | 使用字段 |
|---|---|---|---|
| DDInter 2.0 | 药物-药物、药物-食物相互作用 | 官网下载 | drug_name, interaction_type, interaction_desc, severity |
| 中国药典（2020版） | 药品标准信息 | 公开数据 | 通用名、剂量、用法 |
| 手动整理 | 生活化提醒文案模板 | 团队编写 | 药品类别、模板文案、食物禁忌通俗解释 |

## 数据清洗规则

1. 通用名标准化：统一使用中国药品通用名（CADN），不收录商品名
2. 去重：同一通用名不同剂型合并为一条
3. 禁忌翻译：DDInter 英文数据需翻译为中文，并由药学背景人员审核
4. 严重程度分级：严重/中度/轻度，只对严重和中度做提醒
5. 生活化改写：每条禁忌配一句"通俗解释"（面向老人）

## 数据结构设计

drug_knowledge 表：

| 字段 | 类型 | 说明 | 示例 |
|---|---|---|---|
| generic_name | string | 通用名 | "硝苯地平" |
| category | string | 药品类别 | "降压药-钙通道阻滞剂" |
| common_dosage | string | 常见剂量 | "30mg" |
| taboo_foods | string[] | 禁忌食物 | ["西柚","柚子"] |
| taboo_explanation | string | 通俗解释 | "和降压药一起吃会让药效过强，容易头晕摔倒" |
| timing_note | string | 服用时机建议 | "饭后服用，减少胃部不适" |
| weather_note | string | 天气相关提醒 | "天热时服用注意补水，防止血压过低" |

## 冷启动策略

| 阶段 | 做法 | 覆盖药品数 |
|---|---|---|
| MVP 上线 | 手动导入 50 种 Top 慢病药品 | 50 |
| V1.1 | 根据用户录入频次，优先补充缺失药品 | 100 |
| V2.0 | 批量导入 DDInter 全量 + 自动翻译 | 1000+ |

## 知识库更新流程

1. 用户录入新药品 → 系统查知识库 → 命中则直接使用
2. 未命中 → 加入"待补充清单"
3. 每周人工审补充清单 → 优先处理频率最高的
4. 新增药品需经过：数据录入 → 药学审核 → 文案审核 → 上线
