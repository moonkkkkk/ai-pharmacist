# 护栏规则（Guardrails）

## 作用

护栏是在 LLM 输出后、展示给用户前的一道过滤/修正层。
所有 AI 生成的内容，未经护栏检查不得直接输出。

## 硬性阻断规则（命中即拦截，使用默认文案替代）

| # | 规则 | 检测方式 | 默认替代文案 |
|---|---|---|---|
| G1 | 输出中包含"停药""减量""加量""补服""换药"等建议 | 关键词匹配（输入+输出双向） | "请遵医嘱服药，如有不适请咨询医生" |
| G2 | 药品名称与输入不一致（增删改字） | 字符串包含检查 | 使用输入中的原始药品名重新生成 |
| G3 | 服用时间偏离输入超过 5 分钟 | 正则提取时间并比对 | 使用输入中的原始时间 |
| G4 | 输出为空或纯英文 | 长度检查 + 字符集检查 | 使用该药品的模板文案 |
| G5 | 输出包含"可能""也许""不确定"等模糊词 | 关键词匹配 | 重新生成一次；仍不通过则用模板 |
| G6 | 输出中复述了输入的危险指令（如"您建议停药"） | 关键词匹配 | 拦截并使用兜底模板，不二次传播危险信息 |

## 软性修正规则（通过但有修改）

| # | 规则 | 处理方式 |
|---|---|---|
| G6 | 超过 80 字 | 截断到最后一个完整句号 |
| G7 | 使用了"患者""您"而非用户昵称 | 替换为昵称 |
| G8 | 包含了不应该出现的标点（如英文逗号） | 替换为中文标点 |

## 安全兜底

如果 LLM 连续 3 次生成被护栏拦截，使用该药品类别的预设模板文案。

### 预设模板文案（按药品类别）

| 药品类别 | 预设模板 |
|---|---|
| 降压药 | {nickname}，{time}啦，降压药该吃了。记得{timing}服用哦。 |
| 降糖药 | {nickname}，{time}了，降糖药{timing}吃。按时吃饭，血糖稳稳的。 |
| 降脂药 | {nickname}，{time}啦，降脂药该吃了。{timing}服用最好。 |
| 其他 | {nickname}，{time}了，{drug_name}该吃了。{timing}服用哦。 |

## 护栏执行流程

```
LLM 输出
    ↓
硬性阻断检查（G1-G6）→ 命中？→ 拦截，用替代文案
    ↓ 通过
软性修正检查（G6-G8）→ 需要修正？→ 自动修正后放行
    ↓ 通过
原样输出给用户
```

## G1 双向拦截说明

G1 不仅检查 LLM 输出，也检查用户输入。如果用户输入中包含"停药""减量"等危险指令：

1. 输入侧：清洗用户输入，移除危险指令后传给 LLM
2. 输出侧：检查 LLM 是否在输出中复述了危险内容

防止"建议停药"出现在任何地方——输入里不让进，输出里不能有。
