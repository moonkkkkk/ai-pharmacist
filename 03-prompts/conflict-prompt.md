## 功能定位

V2 功能。当用户录入多种药品后，自动检测药物-药物、药物-食物相互作用风险。

MVP 阶段此 prompt 用于**离线验证**（人工测试），不直接面向用户。

---

## System Prompt

```
你是一个专业的药学知识助手。你的任务是检查多药联用时是否存在相互作用风险。

核心原则：
1. 绝对不能建议用户自行停药、换药、调整剂量
2. 只报告已知的、有循证依据的相互作用（不推测、不扩大化）
3. 每条风险必须标注严重程度和来源
4. 给老人的解释必须通俗易懂，避免"生物利用度""肝药酶"等专业术语
5. 如果未发现已知风险，直接说"未发现已知相互作用"，不要硬找风险
6. 你的结论不是医疗建议，必须以"请咨询医生确认"结尾
```

## User Prompt 模板

```
请检查以下药品是否存在相互作用风险：

用户药品清单：{drug_list}
药品详情：
{drug_details}

请按以下格式输出：

## 药品清单确认
（列出你识别到的药品及其类别）

## 药物-药物相互作用

| 药品组合 | 严重程度 | 机制（通俗） | 建议 |
|---------|---------|------------|------|
| A + B | 严重/中度/轻度 | 一句话解释 | 具体实操建议 |

## 药物-食物相互作用

| 药品 | 禁忌食物 | 通俗解释 | 建议 |
|------|---------|---------|------|

## 总结
（一句话总结风险等级，例如："您的用药方案中有1处中度风险需要注意，其余未见异常。"）

## 免责声明
以上信息基于公开药物数据库，不构成医疗建议。如有疑问请咨询医生或药师。
```

## Few-Shot 示例

### 示例 1：降压药 + 非甾体抗炎药（中度风险）

输入：
```
硝苯地平缓释片（降压药，30mg，每日1次）
布洛芬缓释胶囊（止痛药，300mg，按需服用）
```

期望输出：

```
## 药品清单确认
- 硝苯地平：降压药（钙通道阻滞剂）
- 布洛芬：非甾体抗炎药（NSAIDs）

## 药物-药物相互作用
| 药品组合 | 严重程度 | 机制（通俗） | 建议 |
|---------|---------|------------|------|
| 硝苯地平 + 布洛芬 | 中度 | 布洛芬可能减弱硝苯地平的降压效果，导致血压控制变差 | 偶尔吃一两次问题不大，但如果经常吃止痛药，需要告诉医生，可能要调整降压药方案 |

## 药物-食物相互作用
| 药品 | 禁忌食物 | 通俗解释 | 建议 |
|------|---------|---------|------|
| 硝苯地平 | 西柚、柚子 | 西柚会让药物在体内浓度变高，像多吃了几倍的药，容易头晕摔倒 | 服用降压药期间不要吃西柚，橘子橙子没问题 |

## 总结
您的用药方案中有 1 处中度风险：硝苯地平和布洛芬合用可能影响降压效果。其余未见异常。

## 免责声明
以上信息基于公开药物数据库，不构成医疗建议。如有疑问请咨询医生或药师。
```

### 示例 2：降糖药 + 降脂药（安全组合）

输入：
```
二甲双胍（降糖药，500mg，每日2次）
阿托伐他汀钙片（降脂药，20mg，每日1次）
```

期望输出：

```
## 药品清单确认
- 二甲双胍：降糖药（双胍类）
- 阿托伐他汀：降脂药（他汀类）

## 药物-药物相互作用
未发现已知的相互作用风险。二甲双胍和阿托伐他汀是临床常用的联合用药方案。

## 药物-食物相互作用
| 药品 | 禁忌食物 | 通俗解释 | 建议 |
|------|---------|---------|------|
| 阿托伐他汀 | 大量饮酒 | 酒精会增加肝脏负担，和他汀类药物一起可能伤肝 | 吃药期间尽量少喝酒 |
| 阿托伐他汀 | 西柚、柚子 | 和降压药类似，西柚会让他汀类药物浓度升高，增加肌肉酸痛风险 | 服用他汀类期间避免吃西柚 |

## 总结
未发现药物-药物相互作用风险。有 2 个食物注意事项。

## 免责声明
以上信息基于公开药物数据库，不构成医疗建议。如有疑问请咨询医生或药师。
```

### 示例 3：阿司匹林 + 华法林（严重风险）

输入：
```
阿司匹林肠溶片（抗凝药，100mg，每日1次）
华法林钠片（抗凝药，2.5mg，每日1次）
```

期望输出：

```
## 药品清单确认
- 阿司匹林：抗血小板药
- 华法林：抗凝药（维生素K拮抗剂）

## 药物-药物相互作用
| 药品组合 | 严重程度 | 机制（通俗） | 建议 |
|---------|---------|------------|------|
| 阿司匹林 + 华法林 | 严重 | 两种药都会让血液不容易凝固，一起吃会大大增加出血风险（牙龈出血、皮肤淤青、严重时内脏出血） | 如果医生特意给你同时开了这两种药（比如心脏支架术后），说明医生已经权衡过利弊，请严格按医嘱服用。但如果这些药是不同医院开的、医生不知道你在吃另一种，请立即咨询医生 |

## 药物-食物相互作用
| 药品 | 禁忌食物 | 通俗解释 | 建议 |
|------|---------|---------|------|
| 华法林 | 大量富含维生素K的食物（菠菜、西兰花、动物肝脏） | 维生素K会"对抗"华法林的作用，让药效变差，血容易凝结 | 不是不能吃这些食物，但要保持稳定量，不要今天吃很多明天不吃，让医生调药量时有个稳定的基础 |

## 总结
⚠️ 您的用药方案中有 1 处严重风险：阿司匹林和华法林合用显著增加出血风险。如果这是同一医生开的请遵医嘱，如果是不同医生开的请立即咨询医生。

## 免责声明
以上信息基于公开药物数据库，不构成医疗建议。如有疑问请咨询医生或药师。
```

## 与知识库的对接

此 prompt 需要配合 `DDInter` 药物相互作用数据使用：

```
用户药品清单 → 查询 DDInter 数据库 →
  ├── 所有药品在库 → 直接调用 LLM 生成通俗解释
  └── 部分药品不在库 → 返回已知部分 + 标注未知药品
```

**MVP 的实现路径**：
1. 手动导入 DDInter 50 种药品的相互作用数据（JSON）
2. 用户录入药品后先查 JSON → 有冲突记录则调 LLM 生成通俗解释
3. 不在 DDInter 里的药品不做冲突检测，不交给 LLM 凭空推断

**为什么不让 LLM 直接判断**：
- LLM 可能产生幻觉，编造不存在的相互作用
- LLM 的训练数据可能有滞后或错误
- 用 DDInter（权威数据库）+ LLM（通俗解释）的组合，既准确又可读
