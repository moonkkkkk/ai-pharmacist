## 墨刀制作顺序建议

```
第一步：建 7 个空画板，命名好
第二步：先做 4 个母版（底部导航、Toast、绿色按钮、确认弹窗）
第三步：从简单页面开始 → 老人端 3（我的药品）→ 子女端 4（我的）→ 子女端 1（看板）
第四步：再做复杂页面 → 子女端 2（药品管理）→ 老人端 2（日历）→ 子女端 3（记录）
第五步：最后做老人端 1（提醒弹窗），因为需要做 3 个状态变体
第六步：连接交互（按钮跳转、tab 切换、弹窗出现/消失）
第七步：添加状态变体的画板，用"状态切换"逻辑串联
```

## 墨刀实操提示

1. **字体统一**：新建项目后先设全局字体为 PingFang SC，老人端字号基数设为 18px+
2. **颜色管理**：在"全局样式"里预设 5 个颜色变量——主绿 #07C160、危险红 #FA5151、待办灰 #C0C0C0、警告黄 #FFC300、背景灰 #F5F5F5
3. **底部导航**：用墨刀的"底部导航栏"组件，拖入后配三个 tab 的图标+文字+目标页面
4. **热力图**：在页面 6（用药记录）中，放 28 个（7×4）圆形组件，手动调色最快
5. **搜索自动补全**：墨刀不支持真正的自动补全，用"点击输入框→跳转到一个带下拉列表的画板"来模拟
6. **TTS 播报**：墨刀不支持音频，点"听一遍"按钮后用跳转+Toast"正在播放语音... ✓"模拟即可
