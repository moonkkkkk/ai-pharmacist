# 线框图设计说明

## 整体架构：双端机制与导航

### 一句话说明

**不是两个小程序，是一个小程序 + 两种角色。** 子女用完整管理界面，老人用订阅消息卡片轻交互。

### 双端如何区分

| 维度 | 子女端 | 老人端 |
|------|--------|--------|
| 身份 | 微信一键登录，账号主体 | 微信一键登录（点"允许"） |
| 入口 | 打开小程序 | 点微信订阅消息卡片 |
| 界面 | 完整管理（看板/记录/我的 + 药品管理） | 极简大字（提醒/日历/我的药品） |
| 操作 | 设置、查看、管理 | 语音录药 + 查看 + 点"已吃药" |

**老人也需要登录，但只需点一下"允许"。** 微信小程序一键授权登录，不用输手机号/验证码/密码，对 65 岁以上老人足够简单。老人登录后看到自己的药；子女登录后默认管理自己，点"添加家人"即可代管父母。

### 子女如何关联老人的微信（绑定关系）

"添加家人"不只是填个名字，核心是**关联老人的微信**，这样提醒才能发到老人手机上。

```
子女点"添加家人"
   ↓ 录药（药名/时间/时机/称呼）
   ↓ 生成邀请卡片/小程序码
   ↓ 微信发给老人
老人点开 → 点"允许"授权 → 绑定完成
   ↓
系统拿到老人微信身份，到点发订阅消息
   ↓
老人微信收到提醒卡片 → 点"已吃药"✓ → 记录回传
```

**关联不上怎么办（呼应四级触达）：**

| 情况 | 提醒发到哪 |
|------|-----------|
| 关联了老人微信 | 老人微信订阅消息（最优，老人点按钮） |
| 没关联，但留了手机号 | 短信兜底（L3） |
| 都没关联 | 子女微信 + 子女通知（L4，子女转告） |

### 信息架构（页面层级树）

```
AI 云药师小程序
├── 子女端（微信登录后）
│   ├── 看板（tab 1，首页）
│   │   └── 药品管理（二级页，从看板进入）
│   ├── 记录（tab 2）
│   └── 我的（tab 3）
└── 老人端（微信一键登录）
    ├── 录药向导（首次使用 / 添加药品时进入）
    ├── 提醒弹窗（订阅消息落地页，最高频）
    ├── 今日用药（tab 1）
    └── 我的药品（tab 2）
```

### 导航结构

微信小程序的导航 = **底部 tabBar + 顶部导航栏 + 页面跳转 + 订阅消息入口**，四部分组成。

**1. 底部 tabBar（全局固定，按角色动态配置）**

| 角色 | tab 1 | tab 2 | tab 3 |
|------|-------|-------|-------|
| 子女 | 看板 | 记录 | 我的 |
| 老人 | 今日用药 | 我的药品 | —（无） |

说明：药品管理是二级页，不进 tab；提醒弹窗是订阅消息落地页，也不进 tab。

**2. 顶部导航栏（每页自带）**

- 一级页（tab 页）显示标题：看板 / 记录 / 我的 / 今日用药 / 我的药品
- 二级页显示"← 返回 + 标题"：管理药品、用药记录

**3. 页面跳转**

- 子女端：看板 → 管理药品；看板 → 用药记录（用 navigateTo 保留返回）
- tab 之间：switchTab 切换

**4. 订阅消息入口（老人端独有）**

```
微信服务通知（提醒卡片）
   ↓ 老人点卡片上的"已吃药"
   ✓ 直接记录，无需打开小程序
   ↓ 老人点卡片正文
   进入老人版"今日用药"页（卡片已带身份，无需额外登录）
```

### 页面流转图

```
【子女首次设置】看板 → 管理药品（添加药品）→ 保存 → 回看板
【老人每日】订阅消息卡片 → 点"已吃药"✓ → 完成（不开小程序）
【老人查看】订阅消息卡片 → 点正文 → 今日用药 → 我的药品
【子女查看】看板（下拉刷新）→ 用药记录（看漏服详情）
```

---

## 设计原则

1. **老人端：大字、单任务、零学习成本**。每个页面只做一件事
2. **子女端：信息密度适中、操作高效**。一次设置，长期使用
3. **视觉统一**：温暖、可信赖，微信绿 #07C160 为主色

## 老人端页面

### 页面 0：录药向导（老人自助用，一步一屏 + 语音）

老人独立使用（无子女代管）时的首次设置。核心是**语音录入**，把"打字搜药名"降到"说一句话"。

```
┌─────────────────────────────────┐
│  您好，我来帮您记录每天要吃的药 │
│                                 │
│            [ 开始 ]             │
└─────────────────────────────────┘
                ↓
┌─────────────────────────────────┐
│  请告诉我您每天吃什么药          │
│                                 │
│          🎤 按住说话            │
│                                 │
│  示例：早上饭后吃硝苯地平        │
└─────────────────────────────────┘
                ↓
┌─────────────────────────────────┐
│  我帮您记好了：                 │
│                                 │
│  💊 硝苯地平                     │
│  时间：08:00  时机：饭后         │
│  频次：每天                     │
│                                 │
│  对不对？                       │
│  [ 不对，改一下 ]  [ 对，保存 ] │
└─────────────────────────────────┘
                ↓
┌─────────────────────────────────┐
│  ✓ 设置好了                     │
│  以后每天提醒您按时吃药哦        │
│                                 │
│           [ 知道了 ]            │
└─────────────────────────────────┘
```

规范：
- 每屏只做一件事，字号 20px+
- Step 2 语音是核心：老人按住说话，AI 解析出药名/时间/时机/频次
- Step 3 确认是兜底：AI 解析错了老人可改，宁可多一步确认也不能记错药
- MVP 可用微信原生语音转文字，AI 智能拆解做增强
