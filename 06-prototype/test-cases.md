## 二、功能集成测试（10 条）

| # | 场景 | 操作 | 预期结果 |
|---|------|------|---------|
| F1 | 首次录入→首次提醒 | 录入硝苯地平 08:00 → 等待 08:00 | 老人收到提醒，文案含昵称和药品名 |
| F2 | 正常确认 | 收到提醒 → 点击"已吃药" | 确认时间记录，子女看板绿勾 |
| F3 | L1→L2递进 | 08:00 提醒 → 10min未确认 | L2二次提醒发送 |
| F4 | L3短信触发 | L1+L2未确认 → 30min | 付费用户收到短信（免费版跳过） |
| F5 | L4子女通知 | L3未确认 → 60min | 子女收到漏服通知 |
| F6 | 连续3天文案不重复 | 查看连续3天文案 | 文案有变化 |
| F7 | 知识库未命中 | 录入"XXX罕见药" | 提醒正常，无禁忌提示 |
| F8 | 护栏拦截 | LLM 返回"建议停药" | 护栏拦截，兜底模板 |
| F9 | 多老人绑定 | 子女管理父亲+母亲 | 看板显示两位独立状态 |
| F10 | 网络异常恢复 | 离线确认 → 恢复网络 | 本地缓存同步 |
