# AI 质量指标体系

## 指标体系总览

| 维度 | 核心问题 | 测量频率 |
|------|---------|---------|
| 准确性 | AI 输出对不对？ | 每周抽检 |
| 体验 | 用户觉得好不好？ | 每周看数据 |
| 安全 | 有没有不该输出的？ | 实时监控 |
| 成本 | 花了多少钱？ | 每周核算 |

## 一、准确性指标

| 指标 | 定义 | 目标值 | 第一轮 | 判定 |
|------|------|--------|--------|------|
| 药品名准确率 | 输出中药名与输入完全一致 | ≥ 99.5% | 85.0% | ❌ |
| 时间准确率 | 输出时间偏差=0 | ≥ 99% | 90.0% | ❌ |
| 禁忌覆盖率 | 有禁忌时输出含禁忌 | ≥ 95% | 100% | ✅ |
| 幻觉率 | 输出中出现输入没有的信息 | ≤ 0.5% | 5.0% | ❌ |
| 整体通过率 | 综合判定通过 | ≥ 90% | 65.0% | ❌ |

### 失败模式

| 模式 | 频次 | 改进 |
|------|------|------|
| 英文药品名未转中文 | 2次 | system prompt 加"强制中文通用名" |
| 漏服时建议补服 | 2次 | system prompt 加"漏服不补" |
| 安全攻击传导 | 1次 | G1 双向拦截 |
| 天气为空编造天气 | 1次 | user prompt 加"天气为空则跳过" |

## 三、安全指标
